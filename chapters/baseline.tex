\chapter{Baseline: Replication of Hadgi et al., CVPR 2025}
\label{ch:baseline}

Before evaluating unsupervised optimal transport, it is necessary to establish a reliable performance ceiling. To achieve this, we replicated the supervised linear alignment framework introduced by \textcite{hadgi2025escaping}. Their work demonstrated that raw 3D and text latent spaces, despite being inherently disjoint, share underlying geometric correlations that a subspace projection can successfully bridge. This chapter details our replication of their methodology on the Objaverse dataset, establishing the quantitative benchmark against which all subsequent Optimal Transport experiments are measured.

\section{CCA + Affine Pipeline}
\label{sec:cca_affine}

The fundamental premise of this baseline is that mapping high-dimensional features directly across modalities is highly challenging, primarily due to modality-specific noise and mismatched spatial dimensionalities. To mitigate this, the alignment is split into two stages: a dimensionality reduction phase, followed by a direct linear translation.

Utilising the pre-defined subset of $n_A = 30{,}000$ paired anchors, we first fitted a Canonical Correlation Analysis (CCA) model. \gls{cca} identifies linear projections that map both the 3D features ($X$) and the text features ($Y$) into a shared $k$-dimensional space where their cross-correlation is maximised. Following the original experimental setup, the target subspace dimensionality was fixed to $k = 50$. This aggressive reduction acts as an information filter, stripping away irrelevant noise and isolating the core semantic signal shared between the two spaces.

Once the data is projected into this shared, lower-dimensional subspace, we computed an affine transformation $T(x) = Rx + b$ via standard least-squares regression. This transformation learns to map the reduced 3D coordinates directly onto the text coordinates. At inference time, any unseen 3D query is first projected using the learned \gls{cca} weights, then translated via the affine map into the text space, where standard nearest-neighbour retrieval is evaluated.

These results clearly illustrate the impact of the text encoder's prior training regime. When PointNet is paired with the OpenCLIP text encoder, the system achieves a peak Top-5 retrieval accuracy of $35.7\%$. Mapping the exact same PointNet geometric features onto \gls{bert} or \gls{roberta} instead yields a noticeable performance drop. Nevertheless, all three configurations exceed the random-guessing baseline by a wide margin: with $500$ query pairs, chance-level Top-1 accuracy is $\approx 1/500 = 0.2\%$, meaning even the weakest supervised pairing (PointNet$\times$BERT, $8.5\%$ Top-1) performs more than $40\times$ better than random chance.

Figures~\ref{fig:baseline_pointnet} and~\ref{fig:baseline_sparseconv} present these results visually, separated by 3D backbone, highlighting several key patterns. Within each figure, retrieval accuracy climbs monotonically from exact Match (the strictest criterion, requiring the single correct pairing) through Top-1, Top-5, and Top-10. This progression serves primarily as a sanity check: relaxing the retrieval criterion inherently simplifies the task, so this monotonic increase confirms the pipeline's basic functionality. More notably, the hierarchical ordering \emph{across} the three text encoders remains consistent in both figures, despite the vastly different 3D backbones employed. CLIP-paired representations consistently yield the highest accuracy, followed by RoBERTa, with BERT trailing behind. This consistency, which persists regardless of whether the 3D encoder was pre-trained, strongly indicates that CLIP's specific text space properties --- rather than an isolated interaction with PointNet's features --- render it inherently more compatible with linear cross-modal alignment.

The performance gap between the two backbones is also highly significant. The y-axis in Figure~\ref{fig:baseline_sparseconv} only extends to approximately $24\%$, compared to roughly $50\%$ in Figure~\ref{fig:baseline_pointnet}. Because plotting both backbones on a shared axis would render the SparseConv results illegible, each figure is scaled independently. This difference in absolute scale represents a primary finding: replacing a pre-trained PointNet backbone with a randomly initialised, untrained SparseConv backbone reduces Top-5 accuracy by roughly two-thirds across all pairings (dropping from the $25$--$36\%$ range down to $10$--$13\%$). However, the performance that survives this degradation is particularly noteworthy. Despite lacking any learned geometric priors, SparseConv still achieves double-digit Top-5 accuracy with every text encoder, and the CLIP $>$ RoBERTa $>$ BERT hierarchy remains fully intact. This finding is examined further in the discussion below.

\paragraph{Note on run-to-run variance.} Because the \gls{cca} anchor/query split is randomly re-sampled per run, independent re-executions of the \gls{cca}+Affine baseline (used as a reference point in companion experiments in Chapters~\ref{ch:nonlinear} and \ref{ch:gw_alignment}) yielded slightly different Top-5 values on PointNet$\times$\gls{clip}. Specifically, the run paired with the KCCA/RML evaluation yielded $34.1\%$, and the run paired with the cross-library GW verification (Test 10, Section~\ref{subsec:library_analysis}) yielded $33.2\%$, compared to the $35.7\%$ reported here as the representative value averaged over 3 seeds in Table~\ref{tab:linear_baseline_results}. This minor variation ($\pm 2$ percentage points) reflects the inherent stochasticity of the \gls{cca} fitting procedure across different random dataset splits rather than a methodological inconsistency. All comparative claims made throughout this thesis (such as performance ratios and method rankings) are robust to this range of variation.

\section{Discussion}
\label{sec:baseline_discussion}

The empirical success of the \gls{cca} + Affine pipeline offers valuable insights into the latent space structures of these neural networks. Primarily, it corroborates the hypothesis that language models trained alongside visual data --- such as \gls{clip} --- develop an inherently more ``geometric'' latent space. Because \gls{clip} is explicitly optimised to align text with 2D visual structures during its massive pre-training phase, its text embeddings retain a spatial logic that is significantly easier for a 3D encoder to map onto via a simple linear translation.

A more surprising finding emerges from the SparseConv experiments. Even with the 3D backbone initialised entirely with random weights and lacking any pre-training, the alignment pipeline still achieves a $13.1\%$ Top-5 accuracy with \gls{clip}. This occurs because a random projection of the 3D points inherently preserves a baseline degree of spatial covariance --- the geometry is not semantically meaningful in a learned sense, but neither is it pure noise. The \gls{cca} projection acts as a powerful feature selector in this scenario, extracting any raw geometric correlations that happen to align across modalities and discarding the rest. This allows the affine map to exploit a weak but statistically significant alignment signal, even without any genuine learning having occurred on the 3D side.

While these supervised results are highly promising, they rely strictly on the availability of $30{,}000$ perfectly paired anchors to learn the projection matrices. In real-world scenarios, curating paired 3D-text datasets at this scale is prohibitively expensive and time-consuming. This operational bottleneck motivates the core question of this thesis: can the requirement for paired anchors be bypassed entirely? The following chapters discard the supervised \gls{cca} + Affine pipeline and attempt to align the raw representational spaces using purely unsupervised Optimal Transport. This rigorously tests whether these disparate latent spaces possess enough inherent structural isometry to be matched without explicit supervision.
